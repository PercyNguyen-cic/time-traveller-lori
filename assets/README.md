# Custom Art Assets

Drop your transparent PNG files into the subfolders below. The game will
automatically replace the color-coded placeholder boxes with your artwork.

## Folder structure

```
/assets/
  characters/      - Lori mascot poses
  backgrounds/     - Full-screen scene backgrounds
  tools/           - Tool cards, materials, and finished tools
```

## Required files

## Notes
- All images should be transparent PNGs.
- Until a file is uploaded, the game shows a color-coded placeholder box
  displaying the exact filename and label so you can test the full game loop.
- Placeholder colors by material type: wood = brown, stone = gray,
  bone = cream, cordage/lashing = tan.
